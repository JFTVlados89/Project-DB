---

## Команда проекта и распределение ролей

* **Каменский Артем — Роль: Аналитик**
  * **Этап 0 и 1:** Выбор крупного датасета (от 1 млн строк), нормализация данных (минимум 8 сущностей), составление описания предметной области и карты данных (`data_map.md`), разработка DDL-скрипта (`schema.sql`).
  * **Этап 2:** Проектирование матрицы доступа (распределение прав `SELECT`, `INSERT`, `UPDATE`, `DELETE` для 4+ ролей) и формирование требований к защите данных, включая работу с 152-ФЗ (`access_matrix.md`).
  * **Этап 3:** Написание 6-8 аналитических SQL-запросов (с использованием `JOIN`, `CTE`, оконных функций) и создание витрины данных через `MATERIALIZED VIEW` (`queries.sql`).

* **Якушев Максим — Роль: Администратор / Teamlead**
  * **Этап 4 (Серверный код):** Разработка функций (PL/pgSQL) для расчета бизнес-метрик (например, кредитного риска), написание триггеров для проверки ограничений и журналирования аудита в формате JSON (`triggers_functions.sql`). Сбор статистики ресурсоемких запросов.
  * **Этап 5 (Управление доступом):** Написание DCL-скриптов для создания ролей БД и разграничения привилегий на уровне схемы и таблиц (`roles.sql`).
  * **Управление проектом:** Координация спринтов, контроль качества кода через Pull Requests, проверка архитектуры безопасности.

* **Бурмагин Олег — Роль: Разработчик**
  * **Этап 6 (Программный доступ):** Создание Python-скрипта на базе `psycopg` или `SQLAlchemy` (`db_access.py`) для выгрузки витрин в pandas, проведения параметризованных запросов, обработки транзакций и batch-загрузки. Проверка качества данных.
  * **Этап 7 (Оптимизация):** Проведение `EXPLAIN ANALYZE` для 5 ресурсоемких запросов до и после создания индексов. Создание индексов, применение партицирования и оформление сравнительной статистики в `README.md`.
  * **Визуализация:** Построение физической схемы в виде ER-диаграммы (`er_diagram.png`).

## Структура репозитория

```text
/
├── docs/
│   ├── analysis/
│   │   ├── data_map.md          # Описание предметной области и карта данных
│   │   ├── access_matrix.md     # Матрица доступа и требования к защите
│   │   └── data_flow.png        # Схема потоков данных
│   └── diagrams/
│       └── er_diagram.png       # ER-диаграмма
├── sql/
│   ├── schema.sql               # DDL-скрипт (таблицы, ограничения, индексы)
│   ├── seed.sql                 # Тестовые данные (или Python-скрипт генерации)
│   ├── queries.sql              # Аналитические запросы
│   ├── triggers_functions.sql   # Функции, процедуры, триггеры
│   └── roles.sql                # DCL-скрипты (роли, GRANT/REVOKE)
├── python/
│   └── db_access.py             # Скрипт подключения и выгрузки данных
├── README.md                    # Описание проекта, результаты EXPLAIN ANALYZE
└── report.pdf                   # Пояснительная записка
